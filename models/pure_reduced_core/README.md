# PURE_reduced_core — proposed project model

No reduced SBML or fitted model has been approved or implemented. The
[candidate structure](../../docs/reduction/candidate_core_v0.md) is a review
proposal derived from the PNAS 2017 full translation reference, with every
scientific simplification requiring a human decision recorded against its
original reaction and species IDs.

The proposed core must preserve explicit carrier, phosphate, amino-acid,
tRNA, machinery occupancy and qualified particle accounting. It will only be
built after the [researcher review](../../docs/reduction/human_reduction_review.md)
and chemical-ledger gaps are resolved. Future transcription and GUV transport
will be separate extensions, not edits to the PNAS reference.
