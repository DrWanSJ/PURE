# B0 validation — reversible_conversion

## Identity

- Fixture: `reversible_conversion`
- Benchmark level: `B0`
- Evidence type: `synthetic_fixture`
- Purpose: verify deterministic solver behavior, conservation, positivity, and
  comparison against an independent analytic trajectory.
- Scientific scope: mathematical/software verification only; this is **not**
  a PURE-system model and is not experimental or literature evidence.

## Frozen model

[
A \xrightleftharpoons[k_r]{k_f} B
]

[
\dot A=-k_fA+k_rB, \qquad
\dot B=k_fA-k_rB.
]

Frozen baseline:

| quantity | value |
| --- | ---: |
| `k_f` | 0.3 s^-1 |
| `k_r` | 0.1 s^-1 |
| `A0` | 8.0 uM |
| `B0` | 2.0 uM |
| `t_final` | 30 s |
| solver | ode15s |
| RelTol | 1e-10 |
| AbsTol | 1e-12 |

## Independent analytic reference

[
M_0=A_0+B_0=10\ \mathrm{uM}, \qquad
\lambda=k_f+k_r=0.4\ \mathrm{s^{-1}}.
]

[
A_{eq}=2.5\ \mathrm{uM}, \qquad B_{eq}=7.5\ \mathrm{uM}.
]

[
A(t)=A_{eq}+(A_0-A_{eq})e^{-\lambda t},
\qquad B(t)=M_0-A(t).
]

The analytic implementation is separate from the numerical RHS and never
calls `rhs_reversible_conversion`.

## Registered automated checks

1. RHS spot check at `A=4 uM, B=6 uM`.
2. Derivative conservation identity `dA/dt + dB/dt = 0` at 50 random
   nonnegative states.
3. Full numerical trajectory versus the analytic trajectory using
   `abs(test-ref)/(1 uM + abs(ref))`, target <= 1e-8.
4. Numerical conservation of `A+B=10 uM`, target scaled residual <= 1e-10.
5. Positivity with allowed numerical floor `-1e-12 uM`, with no clipping in
   the RHS.
6. Analytic equilibrium and detailed-balance equality
   `k_f*A_eq = k_r*B_eq`; the finite 30 s endpoint is only a consistency
   check and is not forced equal to the infinite-time limit.
7. Deterministic repeatability for identical inputs.
8. Frozen parameter-value lock.
