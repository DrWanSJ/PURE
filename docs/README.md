# docs/

Documentation by semantics, not by date.

- `project/` — project-level registers: `benchmark_registry.md`,
  `evidence_levels.json`, `licensing_review.md`.
- `validation/` — execution and validation reports (`benchmark_v0.md`).
- `audit/` — audit status and protocols (`audit_status.md`,
  `b1_hardening_report.md`, `manual_fig4_audit_protocol.md`,
  `mutation_test_protocol.md`, human audit checklists, `logs/` with persisted
  test-evidence logs).

Planned (create only when content exists): `models/`, `theory/`
(conservation, nondimensionalization, reduction, stability, flow
thermodynamics), `interfaces/` (frontend/MCP contracts), `reports/`
(gate/final reports). Never create time-based folders (week1/, D6/, final2/…).
